# Dominic's Corner

Create a polished MOBILE-FIRST visual prototype for a private companion app called “Dominic”.

This is a DESIGN PROTOTYPE.

Do not connect:

- Supabase

- databases

- Gemini or any AI API

- authentication

- external APIs

- backend logic

Use realistic mock content only.

The goal is to show what the FINAL APP could look and feel like visually.

DESIGN CONCEPT

The app should feel like:

“a private corner of the internet that has slowly accumulated pieces of someone’s life.”

Combine:

- vintage editorial design

- personal scrapbook

- analog photography

- diary / notebook

- indie personal website

- romantic nostalgia

- music culture

- paper objects

- warm lived-in interiors

- subtle handwritten details

It must NOT look like:

- Linktree

- a SaaS dashboard

- a generic AI chatbot

- a grid of feature cards

- a productivity app

- a generic pink template

STYLE

The design should be intimate, artistic and slightly imperfect, but still elegant and easy to use.

Use generous negative space.

Do NOT put everything inside rounded cards.

Let content become part of the composition.

A photo can simply look like a physical photo.

A note can look like paper.

A letter can look like an envelope.

A song can look like a record or handwritten tracklist.

A diary entry can look like a notebook page.

COLOR PALETTE

Main palette:

- warm cream

- pale dusty pink

- antique rose

- muted cherry red

- cherry wine / deep burgundy

- warm dark brown

Optional small accents:

- muted olive

- butter yellow

- faded blue-gray

- aged paper beige

Avoid:

- bubblegum pink

- purple SaaS gradients

- neon

- glassmorphism

- overly modern tech aesthetics

The visual identity should suggest a future time-of-day system:

Morning:

cream + pale pink

Afternoon:

cream + antique rose

Sunset:

muted cherry + terracotta

Night:

cherry wine + deep brown + cream

Show mainly the daytime / early evening look, but include at least one night-style screen.

TYPOGRAPHY

Use:

1. Elegant editorial serif for major headings.

2. Clean readable font or understated serif for interface text.

3. Handwritten/script font only for intimate accents, notes and signatures.

Do not use script fonts for navigation or long text.

TEXTURES

Use subtle:

- paper grain

- aged paper

- tape

- imperfect photo edges

- Polaroid-style photos

- torn paper

- small handwritten annotations

- tiny doodles

- stamps

- tickets

- delicate vintage details

Keep it sophisticated and uncluttered.

MOBILE NAVIGATION

Use a subtle bottom navigation:

Home

Chat

Room

More

“More” should visually lead to:

Diary

Gallery

Memories

Letters

Music

Now

Little Things

Do not display all of these as giant cards on Home.

CREATE THESE VISUAL SCREENS:

1. HOME

Home must feel like a living personal page, not a menu.

Include:

- current date

- title such as “our little somewhere”

- one candid photo from Dominic’s world

- a small “now” section

- a currently playing song

- one handwritten note to Alloah

- one or two subtle physical details such as a flower, ticket, taped photo or scribble

Example note:

“hope today wasn’t too much.

tell me about it later.

— D”

Use editorial composition and asymmetry.

2. CHAT

Make this simpler and highly usable.

Include:

- Dominic profile photo

- status

- realistic conversation

- text messages

- one photo message

- voice note

- typing state

- attachment controls

Keep the scrapbook aesthetic subtle here.

It should still feel like a believable messenger.

3. ROOM

Create a visual concept of Dominic’s room.

Not 3D.

Show a warm, lived-in bedroom with:

- bed

- guitar

- amp

- clothes

- shoes

- records

- headphones

- desk

- books

- photos

- lamp

- notebook

- personal objects

Visually suggest that some objects could eventually be interactive.

The room should feel inhabited, not staged.

4. DIARY

Design it like a personal notebook / scrapbook.

Include:

- date

- handwritten heading

- text

- taped photo

- song reference

- small doodle

- page number

- subtle pressed flower or paper detail

Do NOT make diary entries into standard cards.

5. LETTERS

Use:

- envelopes

- stamps

- handwritten dates

- paper

- sealed and opened letters

Show examples such as:

“for you”

“open when you miss me”

“18 september”

Make it feel intimate and collectible.

6. GALLERY

Do not make it resemble Instagram.

Use:

- irregular photo sizing

- Polaroids

- film photography

- handwritten captions

- dates

- photo strips

- generous empty space

It should feel like a personal archive accumulated over time.

7. MORE

Create a clean editorial index for:

Diary

Gallery

Memories

Letters

Music

Now

Little Things

Settings

Avoid large rounded cards.

Use typography, thin lines and small decorative elements.

8. NIGHT VERSION

Create one example screen showing how the same app could look at night.

Use:

- deep cherry wine

- dark warm brown

- cream typography

- warm lamp-like accents

It should still clearly feel like the same app.

IMPORTANT

This prototype should look cohesive enough that someone can understand the final product from the screens alone.

Prioritize:

- visual identity

- composition

- atmosphere

- mobile layout

- consistency between screens

Do not spend time building real functionality or backend systems.

The result should feel like a finished design concept for a real mobile app, not a wireframe.
